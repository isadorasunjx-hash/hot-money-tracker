# 📖 跟读背单词 (Word Reader)

一个纯前端的背单词小工具：自己输入英文单词或句子，点一下就能**朗读发音**，并自动显示**中文意思**。

## 功能

- ✍️ 输入英文单词 / 句子（每行一个），一键添加到列表
- ▶️ 点击发音按钮，朗读单个单词或句子（浏览器语音合成）
- 🔊 「全部跟读」依次朗读整个列表，方便跟读练习
- 🌐 自动翻译出中文释义（免费翻译接口，可点击释义重新翻译）
- 🗣 可切换英式/美式等不同语音，调节语速
- 💾 单词列表自动保存在本地浏览器，刷新不丢失

## 使用方法

直接用浏览器打开 `index.html` 即可，无需安装任何东西。

```
# 任选其一
双击打开 index.html
# 或本地起一个静态服务器
python3 -m http.server 8000   # 然后访问 http://localhost:8000/word-reader/
```

## 说明

- 朗读使用浏览器内置的 **Web Speech API**（Chrome / Edge / Safari 支持最好）。
- 中文释义使用免费的 [MyMemory](https://mymemory.translated.net/) 翻译接口，需要联网；
  若翻译失败，点击该行的中文区域可重试。
- 所有数据仅保存在你本地浏览器（localStorage），不上传服务器。
